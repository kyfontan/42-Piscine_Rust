\chapter{Turn in and Submission}

\vspace{0.8cm}

{\LARGE\bfseries Turn in and Submission}

\vspace{0.5cm}

Turn in all your files in a Git repository as usual. All files in your repository
will be evaluated. Double-check your file names and make sure all required files are
present in the repository.

\warningbox{
You must only turn in the files requested by the subject. Make sure you understand
the Rust basics and be ready to correctly explain your code during evaluation.
}
