\chapter{Preamble}

Welcome to the first module of the Rust Piscine.

This module serves as an introduction to the \texttt{Rust} programming language. Rust is a modern systems programming language designed to provide both high performance and strong memory safety guarantees. It focuses on reliability, efficient resource management, and preventing common classes of programming errors at compile time.

The goal of this module is to help you become familiar with the fundamental concepts of the language.\newline
Throughout this module, you will discover:

\begin{itemize}
\item the basic syntax of Rust;
\item variables and immutability;
\item functions;
\item control flow structures;
\item the type system;
\item the first notions of ownership and borrowing.
\end{itemize}

Unlike many other programming languages, Rust introduces concepts that may initially seem unfamiliar. This piscine is designed to help you understand them progressively through practice. The exercises encourage experimentation and learning through implementation.

\textbf{You are encouraged to carefully read the instructions, test your programs frequently, and consult the official documentation when necessary.}

Learning Rust requires precision and attention to detail, but it provides powerful tools to write safe, efficient, and maintainable software.

Good luck and enjoy the Rust Piscine.

\chapter{General Rules}

\vspace{0.5cm}

\begin{itemize}[leftmargin=1.5em, itemsep=0.8em]
    \item Your program should not crash in any circumstances and should not quit unexpectedly.\\
    If it happens, your project will be considered non-functional and your grade will be 0.
    \item Your code must be written in Rust 1.93+
    \item You must compile your programs with the following command to treat all warnings as errors, ensuring cleaner and safer code: \texttt{rustc -D warnings <file.rs>}.
    \item Your programs must respect clippy linter standards
    \item Functions names must match exactly what is requested
    \item Cargo is forbdiden only for this module. Only rustc compiler is authorized.
    \item By Odin, by Thor! Use your brain!!!
\end{itemize}
