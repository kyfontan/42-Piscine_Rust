\chapter{Piscine}

What is a piscine?

Much like the selection piscine, this project is split into many small projects (modules),
with each day introducing a new concept in the language, paradigm, or technology you
have chosen to work on. Validating a piscine requires more than just a day or two of
commitment. To ensure that this piscine is completed correctly, it is recommended that
you take note of everything listed below:

\begin{itemize}[itemsep=8pt]
  \item You can't validate the piscine if you work on only one or two projects.
  \item Try to submit your work every day: even if something isn't finished, it's better to
        submit what you have.
  \item At least two weeks of work: beginning the piscine shouldn't be taken lightly.
  \item Each initialized repository will be automatically closed after one day.
  \item You have two days to complete the required peer evaluations for each module.
  \item It is possible to retry modules without waiting.
\end{itemize}

\vspace{1em}

\begin{warningbox}
  \texttt{It is important not to work on these modules alone. For this reason,
  it is highly recommended to approach these piscines with several
  other students.}
\end{warningbox}

\chapter{Instructions}

To validate this piscine, you must complete the following projects:

\begin{itemize}[itemsep=6pt]
  \item RUST -- Basic syntax and ownership -- 0
  \item RUST -- Primitives, control flow and functions -- 0
  \item RUST -- Structs, enums and pattern matching -- 0
  \item RUST -- Error handling and Option/Result -- 1
  \item RUST -- Traits and generics -- 1
  \item RUST -- Lifetimes and borrowing -- 1
  \item RUST -- Collections and iterators -- 2
  \item RUST -- Concurrency and multithreading -- 2
  \item RUST -- Smart pointers and memory management -- 3
  \item RUST -- Macros and metaprogramming -- 3
\end{itemize}

\vspace{0.5em}

You must validate each project in the specified order. Indeed, it will not be possible
to register for a project if the previous project has not been validated.

  \texttt{You must be registered for this project.}
