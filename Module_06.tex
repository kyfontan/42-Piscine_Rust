\chapter{Project Structure}

This module is a single Cargo project organized into several source files:

\begin{lstlisting}
module_06/
  Cargo.toml
  src/
    main.rs
    logical.rs
    calc.rs
\end{lstlisting}

\begin{itemize}[leftmargin=1.5em, itemsep=0.5em]
    \item \texttt{main.rs} — Entry point. Declares the modules, the \texttt{Bits} struct and the \texttt{Byte} type alias.
    \item \texttt{logical.rs} — Implements fundamental boolean logic gates.
    \item \texttt{calc.rs} — Implements arithmetic circuits and routing components built on top of the logic gates.
\end{itemize}

\vspace{0.5cm}

You must declare in \texttt{main.rs} the following public items:

\begin{lstlisting}
pub mod calc;
pub mod logical;

#[derive(Debug)]
pub struct Bits {
    i0: bool,
    i1: bool,
    i2: bool,
    i3: bool,
}
\end{lstlisting}

The \texttt{Bits} struct represents 4 boolean inputs/outputs used by the multiplexer and demultiplexer.

\subsection*{multiplexer}
A 4-to-1 multiplexer. Selects one of the 4 inputs based on two selector bits \texttt{s0} and \texttt{s1}.

\begin{lstlisting}
pub fn multiplexer(inputs: Bits, s0: bool, s1: bool) -> bool
\end{lstlisting}

The selection logic is:
\begin{itemize}
    \item \texttt{s1=false, s0=false} $\rightarrow$ \texttt{inputs.i0}
    \item \texttt{s1=false, s0=true} $\rightarrow$ \texttt{inputs.i1}
    \item \texttt{s1=true, s0=false} $\rightarrow$ \texttt{inputs.i2}
    \item \texttt{s1=true, s0=true} $\rightarrow$ \texttt{inputs.i3}
\end{itemize}

Implementation hint: each output is a 3-input AND of the corresponding input and the appropriate combination of selector / negated selector bits. The final result is the 4-input OR of all four AND results.

\vspace{1.5cm}

\subsection*{demultiplexer}
A 1-to-4 demultiplexer. Routes a single input bit to one of 4 outputs based on selector bits.

\begin{lstlisting}
pub fn demultiplexer(bit: bool, s0: bool, s1: bool) -> Bits
\end{lstlisting}

Returns a \texttt{Bits} struct where only the selected output is set to the input value; all others are \texttt{false}.

\begin{itemize}
    \item \texttt{s1=false, s0=false} $\rightarrow$ output on \texttt{i0}
    \item \texttt{s1=false, s0=true} $\rightarrow$ output on \texttt{i1}
    \item \texttt{s1=true, s0=false} $\rightarrow$ output on \texttt{i2}
    \item \texttt{s1=true, s0=true} $\rightarrow$ output on \texttt{i3}
\end{itemize}

\vspace{0.3cm}

Example:
\begin{lstlisting}
let res = calc::demultiplexer(true, false, false);
// Bits { i0: true, i1: false, i2: false, i3: false }
\end{lstlisting}
